## 🏛️ Features & Architecture

* **Haute Couture Double Exposure:** Deep obsidian canvas, lunar disk, sumi-e ink washes, and moonlit Alpine lake portal.
* **Monumental Didone Serif Typography:** Averia Serif Libre & General Sans with champagne gold metallic accents.
* **Analogue Film Grain Shader:** SVG fractal noise filter generating organic paper/celluloid texture.
* **432 Hz Procedural Soundscape:** Web Audio API native sine drone (216 Hz, 432 Hz, 648 Hz) with real-time waveform visualizer.
* **Traditional Hanko Artisan Stamp (夢):** Interactive crimson seal with tactile chime feedback.
* **Catalogue Raisonné Timeline:** Series 01 to Series 04 retrospective with geographic coordinates.

# Clone the repository
